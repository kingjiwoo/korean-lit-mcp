# 문법 개념 조회 자료

UTF-8 `entries.json`에 현대 8항목·중세 2항목·근대 표기 1항목을 수록합니다. 초기 묶음의 버전은 `2026-11-01.1`입니다. 수록 수는 확장 상한이 아니며 학교 문법 전 범위나 자유 문장 분석을 지원한다는 뜻이 아닙니다.

- `explanation`은 확인한 사전 설명을 요약한 것이며 원문 전문·문헌 인용으로 표시하지 않습니다.
- `sources`에 실제 표제어의 출처·저자·위치·분류본 버전·확인일·라이선스·변경 내용을 유지합니다.
- `constructed` 예시는 프로젝트가 작성한 합성 예시입니다. `source_example`은 출처 사전의 형태 예시이며, 실제 문헌의 검수 인용문이 아닙니다.
- 옛한글·사설 영역 글리프를 임의 현대화·치환하지 않습니다. 검색 키의 NFC·공백 처리와 응답 텍스트 보존을 구분합니다.
- 같은 용어라도 시대가 다르면 별도 항목입니다. 다른 시대의 자료를 자동 대체하지 않습니다.
- 항목 변경 시 `entry_version`, 출처 확인일·변경 내용과 관련 검증을 갱신합니다. 파일 변경 이력은 Git PR로 관리합니다.
