# 검수 원문

이 폴더는 공유마당에서 만료로 표시된 작품의 제공 TXT, 이용 안내가 확인된 AKS 항목의 전사와 판본별 JSON 메타데이터를 담습니다. 작품의 모든 판본이나 교과서 본문이 같다는 뜻은 아닙니다. 요청 중에는 읽기만 하며 DB를 사용하지 않습니다.

기존 김유정 TXT의 바이트와 CRLF 줄바꿈을 그대로 보존하고 SHA-256으로 확인합니다. 현재 자료는 원본 TXT에 문단 구분이 없어 `source_lines`로 주소를 부여합니다. 이 경우 `¶번호`는 TXT의 물리적 행 번호이며, 인쇄본 문단 번호가 아닙니다. 행 중간에서 단어가 나뉘는 경우도 그대로 반환합니다. 자동 맞춤법 교정이나 현대어 표기 변환을 하지 않습니다.

신규 자료는 출처·권리 근거·판본·다운로드 파일·해시를 확인해 함께 추가합니다. 이 프로젝트의 MIT 라이선스와 원문 자료의 이용 근거는 별개입니다. 출처는 한국저작권위원회 공유마당과 각 메타데이터의 원문 URL로 표시합니다.

## 사미인곡 공급 이력

공유마당 13313606의 공개 TXT를 2026-11-05 수집했다. 원본 UTF-16 BOM 5730바이트 SHA-256 `2df7e38d405ed124bd4b40da9ed898eaf8d6be4f9a7a1192e390e8ca57543111`을 엄격 디코딩하고 `splitlines(keepends=True)[:65]`만 UTF-8로 인코딩했다. 66행부터 현대역이므로 제외했으며 선행 빈 행·CRLF·모든 코드포인트를 유지했다. 저장 파일은 3707바이트, SHA-256 `04082bb8aae54121d5bbb61e20fa24f521a6c1f968700255a9dc9fce8aefc0b1`이다. 원사료 저본 미상이며 기관 제공 전사를 보존하는 검수로, 원사료 교감·교과서 정본 인증은 아니다.

[공급 실증과 권리 근거](../../docs/CLASSICAL-TEXT-SUPPLY.md)를 참고한다. 원본의 현대역 시작과 원문 마지막 행을 대조했으며 제공 과정의 철자 교정은 없다.

## 확대 공급 이력

관동별곡(13313590)·규원가(13313635)·홍길동전 경판30장(13313633)·완판36장(13313634)은 원본 UTF-8에 BOM이 **없음**을 바이트 검사로 확인했다. 엄격 UTF-8 디코딩/재인코딩 결과는 다운로드와 바이트·SHA-256이 같으며 변환하지 않았다. 초기 조사 문서의 BOM 표기를 정정했다. 원본 해시는 공급 실증 표, 저장 해시는 각 manifest에 있다. 파일의 시작·끝·주석/현대역 표지를 검사했으며 별도 현대역 구간은 확인하지 못했다. 귀속 이견·규원가 각주 표지·기관 판본명과 원사료 미교감을 응답에 유지한다.

청산별곡은 AKS 항목에서 전문 소개 문단 바로 뒤 24개 p 요소의 텍스트를 HTMLParser로 추출했다. 각 문단의 코드포인트는 그대로, 문단 사이와 파일 끝에 LF 하나를 삽입했다. HTML 원본 SHA-256 `05ed4b30f7f080d4f9ff9d10c748fa298b0d4de6f65d0571bc66cf0b065fe451`, 저장 TXT 1286바이트 SHA-256 `dab3e29162399dd08eb52509f6546a5cb8e20b4758fc4660b158329d40fa83de`. 24행/8연·첫/끝 행·아래아 조합·괄호 한자가 기관 원고의 인용 구간과 같음을 확인했다. 원고 해설·미디어는 포함하지 않는다. `licensed`와 `aks-public-use` 표시를 사용하며 출처 표시 **청산별곡, 『한국민족문화대백과사전』**를 유지해야 한다. 고문헌 원사료가 아닌 기관 인용 전사다.

홍길동전 두 판본은 같은 work_id와 서로 다른 edition_id를 가진다. get_passage는 edition_id 미지정 시 임의로 고르지 않는다. 구운몽은 재사용 가능한 정확한 전사를 아직 확보하지 못해 이 폴더에 본문이 없다. 검색 식별·뷰어 열람을 텍스트 공급으로 오인하지 않는다.
