# 검수 원문

이 폴더는 공유마당에서 만료로 표시된 작품의 제공 TXT와 판본별 JSON 메타데이터를 담습니다. 작품의 모든 판본이나 교과서 본문이 같다는 뜻은 아닙니다. 요청 중에는 읽기만 하며 DB를 사용하지 않습니다.

기존 김유정 TXT의 바이트와 CRLF 줄바꿈을 그대로 보존하고 SHA-256으로 확인합니다. 현재 자료는 원본 TXT에 문단 구분이 없어 `source_lines`로 주소를 부여합니다. 이 경우 `¶번호`는 TXT의 물리적 행 번호이며, 인쇄본 문단 번호가 아닙니다. 행 중간에서 단어가 나뉘는 경우도 그대로 반환합니다. 자동 맞춤법 교정이나 현대어 표기 변환을 하지 않습니다.

신규 자료는 출처·권리 근거·판본·다운로드 파일·해시를 확인해 함께 추가합니다. 이 프로젝트의 MIT 라이선스와 원문 자료의 이용 근거는 별개입니다. 출처는 한국저작권위원회 공유마당과 각 메타데이터의 원문 URL로 표시합니다.

## 사미인곡 공급 이력

공유마당 13313606의 공개 TXT를 2026-11-05 수집했다. 원본 UTF-16 BOM 5730바이트 SHA-256 `2df7e38d405ed124bd4b40da9ed898eaf8d6be4f9a7a1192e390e8ca57543111`을 엄격 디코딩하고 `splitlines(keepends=True)[:65]`만 UTF-8로 인코딩했다. 66행부터 현대역이므로 제외했으며 선행 빈 행·CRLF·모든 코드포인트를 유지했다. 저장 파일은 3707바이트, SHA-256 `04082bb8aae54121d5bbb61e20fa24f521a6c1f968700255a9dc9fce8aefc0b1`이다. 원사료 저본 미상이며 기관 제공 전사를 보존하는 검수로, 원사료 교감·교과서 정본 인증은 아니다.
