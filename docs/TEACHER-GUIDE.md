# 교사 사용 안내

이 서버는 검수한 원문을 가져오고 자료 속 인용을 문자열로 대조합니다. 현재 제공 자료는 김유정의 「동백꽃」과 「봄·봄」 공유마당 TXT 판본입니다. 해석이나 문제의 정답 타당성까지 검증하는 기능은 아닙니다.

## 연결

운영자가 제공하는 원격 MCP URL과 파일럿 접근 토큰으로 Claude 커스텀 커넥터를 추가합니다. 고정 요청 헤더 `Authorization`에 `Bearer <접근 토큰>`을 설정합니다. 기관 API 키를 교사가 발급받을 필요는 없습니다. 현재 계정에서 연결 메뉴와 헤더 설정을 사용할 수 있는지 실제로 확인해야 합니다.

운영자는 접근 토큰을 비공개로 전달합니다. 학습지·대화·스크린샷·공개 URL에 토큰을 붙이지 않습니다. 연결에 문제가 있으면 운영자에게 오류 시점과 상황을 전달하고 토큰이나 교과서 본문은 첨부하지 않습니다.

## 원문으로 자료 만들기

1. 「동백꽃」의 김유정 작품을 찾아 달라고 요청합니다.
2. 제공 판본을 확인하고 필요한 범위를 가져오도록 합니다.
3. 문제를 만든 뒤 지문과 모범답안의 인용을 모두 검증해 달라고 요청합니다.
4. 표기 차이·불일치·미확인 결과를 보고 수정한 인용을 다시 검증합니다.
5. 자료 하단에 작품·작가·판본·출처 URL을 표시합니다.

예시 요청: “김유정 「동백꽃」의 제공 판본을 확인하고 필요한 부분을 가져와 줘. 서술형 문제를 만든 뒤 지문과 모범답안의 모든 인용을 검증하고 검사 범위를 알려 줘.”

현재 TXT의 `¶번호`는 파일의 물리적인 행 주소이며 교과서 문단 번호와 다를 수 있습니다. 줄 중간의 단어 분리와 표기도 제공 파일 그대로입니다. 시험에 쓰는 교과서와 판본을 대조하고, 다르면 교사가 제공한 본문을 기준으로 검증합니다.

## 현대 작품과 교사 제공 본문

서버가 원문을 제공하지 않는 작품은 교사가 본문을 붙여넣고 그 텍스트와 대조합니다. 검증만으로 작품의 저작권 상태를 판단하지 않습니다. 서버는 이 본문과 초안을 파일·캐시·로그에 보관하지 않습니다. Claude에 입력한 대화의 보관 정책은 서버와 별개입니다.

이 모드는 전달받은 문자열을 기준으로 비교할 뿐, 그 텍스트가 실제 정본인지 또는 교사가 직접 제공했는지 인증하지는 않습니다. 모델의 기억으로 만든 본문을 기준으로 삼지 말고 확인한 자료를 사용합니다.

## 판정 읽기

| 판정 | 의미 | 할 일 |
| --- | --- | --- |
| `exact` | 제출한 인용이 해당 원문에 문자 그대로 존재 | 출처·판본과 위치 확인 |
| `orthography` | 공백·따옴표·유니코드 표기 차이 | 차이를 확인하고 사용할 표기 결정 |
| `mismatch` | 가까운 후보가 있지만 인용이 다름 | 원문과 대조해 수정 후 재검증 |
| `not_found` | 검사에서 인용을 확인하지 못함 | 판본·본문·생략 여부 확인 |

같은 구절이 여러 곳에 있으면 정확히 같은 문자열도 위치를 추가 확인해야 합니다. 교정 후보는 제안이며 자동 정답이 아닙니다.

## 초안 검사 범위

현재는 `“…”`, `‘…’`, `「…」`, `『…』`, ASCII 큰따옴표, `<quote>…</quote>`와 `<passage>…</passage>` 표시를 검사합니다. 중첩·표시 없는 인용·빈칸·밑줄 서식은 확인이 더 필요합니다. 필요한 인용은 개별 목록으로 명시해 검사할 수 있습니다.

`all_submitted_exact`가 참이어도 제출하거나 추출한 인용의 범위에만 해당합니다. `coverage`, 검사 개수, `unverified_regions`를 함께 확인합니다. 서버는 Claude가 검증을 건너뛰거나 이후 답변을 바꾸는 것을 막을 수 없으므로, 판정 없는 결과물을 검증 완료 자료로 사용하지 않습니다.
