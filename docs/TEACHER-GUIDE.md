# 교사 사용 안내

이 서버는 검수한 원문을 가져오고 자료 속 인용을 문자열로 대조합니다. 현재 제공 자료는 김유정의 「동백꽃」과 「봄·봄」 공유마당 TXT 판본입니다. 해석이나 문제의 정답 타당성까지 검증하는 기능은 아닙니다.

## 연결

운영자가 제공하는 공개 MCP URL을 Claude 커스텀 커넥터에 추가합니다. 사용자 키 발급·회원가입·인증 헤더 없이 연결합니다. 인증 방식을 묻는 경우 로그인 없는 방식을 선택합니다. 현재 계정에서 커넥터 추가와 실제 호출이 되는지 확인해야 합니다.

기관 API 키는 외부 검색을 활성화할 때 운영자가 서버에만 설정합니다. 교사가 발급받거나 입력할 필요는 없습니다. 연결에 문제가 있으면 운영자에게 오류 시점과 상황을 전달하고 비밀값이나 교과서 본문은 첨부하지 않습니다. 호출 제한이 표시되면 안내된 시간 뒤 다시 시도합니다.

## 원문으로 자료 만들기

1. 「동백꽃」의 김유정 작품을 찾아 달라고 요청합니다.
2. 제공 판본을 확인하고 필요한 범위를 가져오도록 합니다.
3. 문제를 만든 뒤 지문과 모범답안의 인용을 모두 검증해 달라고 요청합니다.
4. 표기 차이·불일치·미확인 결과를 보고 수정한 인용을 다시 검증합니다.
5. 자료 하단에 작품·작가·판본·출처 URL을 표시합니다.

예시 요청: “김유정 「동백꽃」의 제공 판본을 확인하고 필요한 부분을 가져와 줘. 서술형 문제를 만든 뒤 지문과 모범답안의 모든 인용을 검증하고 검사 범위를 알려 줘.”

현재 TXT의 `¶번호`는 파일의 물리적인 행 주소이며 교과서 문단 번호와 다를 수 있습니다. 줄 중간의 단어 분리와 표기도 제공 파일 그대로입니다. 시험에 쓰는 교과서와 판본을 대조하고, 다르면 교사가 제공한 본문을 기준으로 검증합니다.

## 현대 작품과 교사 제공 본문

서버가 원문을 제공하지 않는 작품은 교사가 본문을 붙여넣고 그 텍스트와 대조합니다. 검증만으로 작품의 저작권 상태를 판단하지 않습니다. 서버는 이 본문과 초안을 파일·캐시·로그에 보관하지 않습니다. Claude에 입력한 대화의 보관 정책은 서버와 별개입니다.

이 모드는 전달받은 문자열을 기준으로 비교할 뿐, 그 텍스트가 실제 정본인지 또는 교사가 직접 제공했는지 인증하지는 않습니다. 모델의 기억으로 만든 본문을 기준으로 삼지 말고 확인한 자료를 사용합니다.

## 판정 읽기

| 판정 | 의미 | 할 일 |
| --- | --- | --- |
| `exact` | 제출한 인용이 해당 원문에 문자 그대로 존재 | 출처·판본과 위치 확인 |
| `orthography` | 공백·따옴표·유니코드 표기 차이 | 차이를 확인하고 사용할 표기 결정 |
| `mismatch` | 가까운 후보가 있지만 인용이 다름 | 원문과 대조해 수정 후 재검증 |
| `not_found` | 검사에서 인용을 확인하지 못함 | 판본·본문·생략 여부 확인 |

같은 구절이 여러 곳에 있으면 정확히 같은 문자열도 위치를 추가 확인해야 합니다. 교정 후보는 제안이며 자동 정답이 아닙니다.

## 초안 검사 범위

현재는 `“…”`, `‘…’`, `「…」`, `『…』`, ASCII 큰따옴표, `<quote>…</quote>`와 `<passage>…</passage>` 표시를 검사합니다. 중첩·표시 없는 인용·빈칸·밑줄 서식은 확인이 더 필요합니다. 필요한 인용은 개별 목록으로 명시해 검사할 수 있습니다.

`all_submitted_exact`가 참이어도 제출하거나 추출한 인용의 범위에만 해당합니다. `coverage`, 검사 개수, `unverified_regions`를 함께 확인합니다. 서버는 Claude가 검증을 건너뛰거나 이후 답변을 바꾸는 것을 막을 수 없으므로, 판정 없는 결과물을 검증 완료 자료로 사용하지 않습니다.

## 고전 자료 찾기

`search_classical_text`는 고전원문(`classic`), 한국문집총간(`anthology`), 한국고전총간(`corpus`)의 본문(`body`) 또는 기사명(`title`)을 검색합니다. 예: “한국문집총간에서 春을 본문 검색해 줘.” 결과는 기관의 검색 발췌와 자료 링크이며 전체 작품이 아닙니다. 검색 결과 ID를 `get_passage`의 검수 작품 ID로 사용할 수 없습니다. 국문 시조·가사·고전소설 전체를 포괄한다고 보장하지 않습니다. 문법 분석 도구는 아직 제공하지 않습니다.

### 작품 작가와 검색 문헌 저자

작품을 찾을 때는 `target=title`로 기사명을 먼저 검색하고, 관련 언급을 찾을 때는 `target=body`로 검색합니다. 기존 요청의 기본값은 `body`입니다. 결과의 `search_target`으로 실제 검색 범위를 확인합니다. 기사명 검색이 정확한 제목 일치를 보장하지 않으며, 제목이 같아도 작품 전문을 찾았다는 뜻은 아닙니다.

`document_author`는 기관 레코드의 저자이고 `author`는 같은 값을 유지하는 기존 클라이언트 호환 필드입니다. `author_role=source_record_author`로 역할을 표시합니다. 작품 작가는 확인되지 않아 `work_author=null`로 반환합니다. 예를 들어 사미인곡 검색에서 임하필기의 저자가 이유원으로 나오더라도 정철의 작품 작가 정보가 바뀐 것은 아닙니다. 문헌 저자를 작품 작가로 복사하지 않습니다.

결과가 없으면 해당 검색 범위에서 찾지 못했다고 안내합니다. 관련 기록만 나오면 원문을 찾았다고 안내하지 않습니다. 기관의 검색 발췌에 포함된 강조 마크업도 작품의 원문 표기로 간주하지 않습니다.

### 작품 후보와 동음 검색 결과

`work_candidates`는 규원가·사미인곡·홍길동전의 검수 제목·이칭과 귀속 참고 정보입니다. 근거 링크와 귀속 이견을 확인합니다. `identity_id`는 원문 조회 ID가 아닙니다.

`match_kind=title_candidate`는 같은 제목의 기사 후보, `body_mention`은 발췌의 이칭 문자열 언급, `unconfirmed_search_match`는 알려진 이칭과 불일치, `unclassified`는 검수 이칭 미등록입니다. 규원가 검색의 九原可는 불일치로 구분합니다. 모든 레코드의 `identity_status=unconfirmed`이며 동일 작품이나 판본을 확정하지 않습니다. 다른 작품의 동명 기사는 자동 제거하지 않으므로 문헌을 직접 확인합니다. 이칭 목록의 범위와 검수 근거는 [식별 계약](decisions/0004-classical-identity.md)을 참고하세요.
