# 문법·고전 문법 도구 계약

상태: PR 단위 구현 진행. 국립중앙도서관 키 없이 검수 자료를 번들에 포함하는 조회 도구를 구현한다. 도구 내부 LLM 호출·DB·문장 자동 분석은 도입하지 않는다. 완료 표시는 각 PR의 리뷰·최종 검사와 실제 배포 결과를 확인한 뒤 갱신한다.

## 목표와 자료 근거

교사가 현대·중세·근대 국어 문법 개념을 확인할 때, 출처와 시대가 확인된 설명·용례를 찾는다. 하나의 `lookup_grammar` 도구로 시작한다. 임의 문장의 정답 판정이나 자동 형태소 분석은 근거와 판정 체계가 확보된 다음 별도 설계한다.

PDF 링크가 변경되면 국립국어원 [기타 자료 목록](https://www.korean.go.kr/front/etcData/etcDataList.do?mn_id=208)에서 「제14회 국외 한국어 교원 연수 교재」(2010), 조규태 「한국어사」로 다시 찾는다.

이번 조사에서 중세·근대 국어 문법을 포괄하는 무키 공식 API는 확인하지 못했다. 이것이 API가 존재하지 않는다는 결론은 아니다. 공개 열람 가능 여부와 설명·용례의 재배포 허락은 별도 확인한다.

## 요청 계약

- `term`: 공백만 있는 입력 거부, 최대 100자. 문법 개념 또는 검수된 형태 표제어.
- `period`: `modern`, `middle`, `early_modern` 중 필수 하나. 현대 자료를 중세 결과로 자동 대체하지 않는다.
- `limit`: 기본 5, 1~10. 검수 항목만 반환한다.

첫 버전에는 자유 입력 문장·초안·파일·임의 출처 URL을 받지 않는다. 문법 용어의 동의어·표기 차이는 검토한 별칭만 검색에 사용하고 옛한글 원문 표기를 변형하지 않는다.

## 응답 계약

기존 Envelope를 재사용한다. 공통 source는 검수 문법 자료 묶음을 표시하고, 항목별 sources에 실제 근거를 기록한다. 이번 CC BY-SA 자료는 퍼블릭 도메인이 아니므로 공통 copyright를 protected로 표시하고, note와 항목별 sources에 허용된 이용조건을 함께 전달한다. 미검색은 unknown이다. retrieved_at은 응답 생성시각으로 sources의 확인일과 구분한다. 오류와 items는 공존하지 않는다. `items`의 각 항목은 다음 정보를 갖는다.

- `entry_id`, `term`, `period`: 검수 항목과 시대 식별.
- `explanation`: 검수 자료에 근거해 작성한 설명. 출처에 없는 설명을 생성해 채우지 않음.
- `sources`: 자료명·저자·URL·페이지/절 위치·확인일·이용조건·검수 항목 버전.
- `examples`: 검수된 용례만 포함. 각 용례는 출처/판본/위치를 가짐. 원문 인용과 합성 예문을 구분하고 합성 예문을 역사 문헌 용례로 표시하지 않음.
- `limitations`: 학설·교과서 체계·시대 범위 등 적용 제한.

응답 note에는 개념 조회만 수행했으며 임의 문장 분석·시험 정답 검증은 수행하지 않았다고 표시한다. 이를 항목별 상수 필드로 추가하지 않는다.

정상 미검색은 빈 items와 해당 시대의 검수 항목을 찾지 못했다는 note를 반환한다. 이 결과를 용어나 현상 자체가 없다는 뜻으로 안내하지 않는다. 데이터 형식 오류·외부 장애는 기존 error 코드 계약을 따르며 성공 응답으로 숨기지 않는다. 상충하는 설명은 출처별로 표시하고 근거 없이 하나를 정답으로 고르지 않는다.

## 구현 PR과 검사 기준

아래 G 번호는 작업 단계이며 GitHub PR 번호와 다르다. 각 작업 PR은 Claude Code Opus 교차 리뷰 → 수정 → ponytail 리뷰 → 최종 필수 검사 → `develop` squash 병합 순서로 진행한다. Claude 사용량 한도 동안은 사용자 승인에 따라 별도 Codex 세션의 읽기 전용 독립 리뷰로 임시 대체하고, 제품 간 교차 리뷰와 구분해 실제 제품·모델·근거를 기록한다. 한도 복구 후 기본 방식으로 돌아간다. 후속 PR은 최신 develop에서 시작한다.

| 단계 | 브랜치 | 범위 | 완료 기준 | 상태 |
| --- | --- | --- | --- | --- |
| G-01 | `chore/grammar-corpus` | 출처·라이선스 조사, PR 계획, 검수한 설명·예시·별칭·시대·버전과 데이터 이용조건 | 모든 항목의 원출처·위치·이용조건 확인. 합성 예문과 출처 예시 구분. 미허용 자료 제외. 자료 파일 자체 검증 | PR #37 develop 병합 완료 |
| G-02 | `feat/grammar-lookup` | 요청·자료 형식 검증, 크기 제한 로더, 시대별 용어·별칭 조회와 오류/미검색 계약 | 현대/중세/근대 격리, 옛한글 보존, 정확 일치 우선·결과 상한, 중복 ID·누락 출처·잘못된 이용조건·파일 오류 테스트 통과 | 구현·독립 리뷰 수정 완료, 최종 검사·통합 대기 |
| G-03 | `feat/grammar-mcp` | `lookup_grammar` MCP 등록, 기동 시 로딩, 지표 허용 목록, Vercel 번들, 교사·운영 안내와 실제 HTTP 검사 | 키·LLM 없이 세 시대 조회, 별칭·미검색·입력 오류 확인. 기존 도구 회귀 검사와 Python·Markdown·컨테이너 CI 통과 | 대기 |

초기 데이터는 현대 8항목, 중세 2항목, 근대 표기 1항목을 확인한 출처에 맞춰 제공한다. 이는 수록 상한이 아니며 문법 전 범위의 구현 완료를 뜻하지 않는다. 추가 항목은 동일한 출처·이용조건·검수 기준으로 별도 PR에서 늘린다. 근대의 중철은 역사적 표기법 항목이며 근대 문법 체계 전체를 대체하지 않는다.

조회는 용어와 검토한 별칭에 한정하고 NFC·공백 차이만 검색 키에서 처리한다. 원자료의 옛한글·사설 영역 문자는 응답에서 변환하지 않는다. 현대 항목을 중세/근대 요청의 대체 결과로 반환하지 않는다. 자료·스키마 오류는 기동 실패로 드러내며, 미검색은 해당 시대의 검수 자료에 없다는 뜻으로만 안내한다.

출처 텍스트의 CC BY-SA 2.0 KR 조건을 데이터 폴더의 라이선스와 응답 출처에 유지한다. 프로그램의 MIT 라이선스와 구분하며 사전 예시의 외부 저작물 인용·수어·이미지·영상은 포함하지 않는다. 번들 조회는 기관 API를 호출하지 않아 추가 API 키가 필요하지 않다. 외부 사전 API 도입은 별도 발급·실증 PR로 남긴다.

릴리스 조건이 실패하면 main 병합 또는 배포 완료 표시를 진행하지 않는다. 배포 실패 시 직전 production deployment로 되돌리는 기존 운영 절차를 따른다. 문법 조회 성공을 임의 문장 분석·시험 정답 검증 성공으로 보고하지 않는다.

자료 수만 늘린 임의 설명을 완료로 간주하지 않는다. 근거·시대·별칭·예시·적용 한계는 자료 PR에서 검토하며, 기관의 감수나 실제 교사 파일럿을 완료했다고 표시하지 않는다.
