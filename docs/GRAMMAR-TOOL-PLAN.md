# 문법·고전 문법 도구 계약

상태: 설계 확정안. MCP 도구는 아직 등록하지 않는다. 국립중앙도서관 키 없이 할 수 있는 근거 자료 조사와 계약 설계이며, 언어 분석 구현 완료를 뜻하지 않는다.

PDF 링크가 변경되면 국립국어원 [기타 자료 목록](https://www.korean.go.kr/front/etcData/etcDataList.do?mn_id=208)에서 「제14회 국외 한국어 교원 연수 교재」(2010), 조규태 「한국어사」로 다시 찾는다.

이번 조사에서 중세·근대 국어 문법을 포괄하는 무키 공식 API는 확인하지 못했다. 이것이 API가 존재하지 않는다는 결론은 아니다. 공개 열람 가능 여부와 설명·용례의 재배포 허락은 별도 확인한다.

## 요청 계약

- `term`: 공백만 있는 입력 거부, 최대 100자. 문법 개념 또는 검수된 형태 표제어.
- `period`: `modern`, `middle`, `early_modern` 중 필수 하나. 현대 자료를 중세 결과로 자동 대체하지 않는다.
- `limit`: 기본 5, 1~10. 검수 항목만 반환한다.

첫 버전에는 자유 입력 문장·초안·파일·임의 출처 URL을 받지 않는다. 문법 용어의 동의어·표기 차이는 검토한 별칭만 검색에 사용하고 옛한글 원문 표기를 변형하지 않는다.

## 응답 계약

기존 Envelope를 재사용한다. 공통 source는 검수 문법 자료 묶음을 표시하고, 항목별 sources에 실제 근거를 기록한다. 공통 copyright는 권리 상태를 일괄 확정할 수 없으면 unknown이며 항목의 이용조건을 함께 표시한다. retrieved_at은 응답 생성시각으로 sources의 확인일과 구분한다. 오류와 items는 공존하지 않는다. `items`의 각 항목은 다음 정보를 갖는다.

- `entry_id`, `term`, `period`: 검수 항목과 시대 식별.
- `explanation`: 검수 자료에 근거해 작성한 설명. 출처에 없는 설명을 생성해 채우지 않음.
- `sources`: 자료명·저자·URL·페이지/절 위치·확인일·이용조건·검수 항목 버전.
- `examples`: 검수된 용례만 포함. 각 용례는 출처/판본/위치를 가짐. 원문 인용과 합성 예문을 구분하고 합성 예문을 역사 문헌 용례로 표시하지 않음.
- `limitations`: 학설·교과서 체계·시대 범위 등 적용 제한.

응답 note에는 개념 조회만 수행했으며 임의 문장 분석·시험 정답 검증은 수행하지 않았다고 표시한다. 이를 항목별 상수 필드로 추가하지 않는다.

정상 미검색은 빈 items와 해당 시대의 검수 항목을 찾지 못했다는 note를 반환한다. 이 결과를 용어나 현상 자체가 없다는 뜻으로 안내하지 않는다. 데이터 형식 오류·외부 장애는 기존 error 코드 계약을 따르며 성공 응답으로 숨기지 않는다. 상충하는 설명은 출처별로 표시하고 근거 없이 하나를 정답으로 고르지 않는다.

## 구현 PR과 검사 기준

1. 근거자료 PR: 재사용 가능한 설명·용례를 확보해 항목별 manifest(출처·권리·시대·검수일·버전)를 기록한다. 원문·저작권 불명 자료를 넣지 않는다. 키가 필요한 사전은 별도 발급 후 라이브 응답을 실증한다.
2. 조회 PR: 검수 자료를 읽는 조회와 MCP 등록, 내용 없는 지표 허용 목록, 교사 안내와 도구 목록 테스트를 함께 추가한다. 새 DB나 형태소 분석 의존성은 도입하지 않는다.
3. 검증: 현대/중세/근대 구분, 동음 형태·다의어, 미검색, 출처 누락, 범위 밖 요청, 옛한글 무변형, 합성/문헌 용례 구분, 인용 위치 보존을 검사한다. 재사용 근거 없는 항목은 공개하지 않는다.

자료 수만 늘린 임의 설명을 이번 설계의 완료로 간주하지 않는다. 현재 필요한 것은 사용자 추가 답변보다 자료 확보와 검수다. 사전 API를 선택하면 국립중앙도서관과 별개의 키 발급이 후속 외부 의존성이 된다.
