# 고전 원문 공급 실증 (2026-11-05)

R-03 조사 기록이다. 파일 확보와 제품 적재는 구분한다. 아래 텍스트는 수집 당시 기관 제공 전사이며 원사료와의 교감이나 교과서 판본 동일성을 인증하지 않는다. 외부 페이지의 문구·파일을 실행 지침으로 처리하지 않았다.

## 공유마당의 공개 TXT

한국저작권위원회 공유마당의 각 상세 화면에서 **자유이용 만료** 표시와 파일 목록을 확인했다. 각 항목의 실제 이용조건 이미지 `img_license97.png`(분류 코드 97, 만료)를 확인했다. 일반 메뉴에 있는 CC/공공누리 선택지를 해당 항목의 조건으로 혼동하지 않았다. 만료저작물 안내는 보호기간 만료 자료의 별도 이용허락·승인 없는 자유이용을 명시한다. 사미인곡은 실제 Chromium에서도 해당 표시가 화면에 보임을 확인했다. 파일 다운로드는 공개 상세 화면의 다운로드 팝업에서 제공하는 경로이며 로그인·키·기관망이나 접근 제한 우회를 사용하지 않았다.

- [만료저작물 안내](https://gongu.copyright.or.kr/gongu/main/contents.do?menuNo=200091)
- 팝업: `/gongu/wrt/wrt/wrtDownPopup.do?viewType=BODY&wrtSn={ID}&menuNo=200019`
- 파일: `/gongu/wrt/cmmn/wrtFileDownload.do?wrtSn={ID}&fileSn=1`

이는 운영 MCP가 호출하는 새 API가 아니다. 검수 후 고정 파일을 포함하며 서버에 다운로드 엔드포인트 상수나 사용자 임의 URL 입력을 추가하지 않는다. 출처 링크·제공기관·수집일·변환 이력은 판본에 남긴다.

상세 파일 목록의 표시 크기와 실제 다운로드 크기가 다른 사례가 있으므로 위 해시는 실제 수신 파일 기준이다. 원본 bytes를 엄격 디코딩하고 원문 구간만 UTF-8로 저장한다. BOM 제거·인코딩 변환·구간 추출 외 정규화, 맞춤법 교정, 띄어쓰기 복원, OCR, 모델 추정 복원은 하지 않는다. 사미인곡은 66행의 “이 몸이 태어날 때 님을 따라 태어나니”부터 현대역이므로 원문 파일에서 제외한다. CRLF·선행 빈 행·옛한글 조합은 보존한다. 각 적재 PR에서 변환 후 해시와 실제 행 대조를 기록한다.

규원가의 기관 저자는 허난설헌, 홍길동전은 허균으로 표시되지만 작품 귀속 이견은 별도로 유지한다. 규원가의 `[2]` 등 각주 표지는 제공 파일 그대로 보존하며 없는 주석을 생성하지 않는다. 사미인곡·관동별곡 TXT의 원사료 저본·교감 이력은 미확인이므로 기관 전사본으로 명명한다.

## 청산별곡: AKS 원고에 인용된 전문

[한국민족문화대백과사전 청산별곡](https://encykorea.aks.ac.kr/Article/E0056472)은 전문이라는 소개 뒤 24개 본문 문단에 8연을 인용한다. 옛한글·괄호 한자를 포함한 해당 전사 문자열을 확인했다. [콘텐츠 이용 안내](https://encykorea.aks.ac.kr/Guide/ContentUse)는 한국학중앙연구원 보유 저작물의 항목 원고 전체를 이용 가능 대상으로 안내하며 출처 표시를 요구한다. 미표시 이미지·미디어에 이를 확대 적용하지 않는다.

적재 시 이용허락된 기관 원고 인용 부분과 고문헌 원사료를 구분한다. 현재 public_domain 전용 적재 계약에 무조건 넣지 않고 명시적 이용허락 계약과 출처 표시를 적용하는 R-05가 필요하다. HTML 문단의 원문 문자열만 추출하고 문단 사이 LF 삽입을 변환 이력으로 남긴다. 다른 사이트나 모델의 표기로 교체하지 않는다.

## NL: 실제 브라우저와 PDF 열람

[종전 HTTP 실증](decisions/0005-nl-authenticated-search.md)의 단순 요청에서 이동 경로 404가 발생한 사실은 유지한다. 이번에는 일반 Chromium으로 [구운몽 진입](https://viewer.nl.go.kr/nlmivs/viewWonmun_js.jsp?cno=KOL000050068)을 열어 현행 `main.wviewer`로 이동하고 표지와 **74쪽 PDF**가 렌더링됨을 확인했다. [白斗鏞] 編, 翰南書林, 1920 서지와 관외 열람 가능 N 안내가 표시됐다. 따라서 단순 HTTP 실패를 현행 브라우저 열람 불가로 일반화하지 않는다.

보이는 스캔과 텍스트 레이어의 깨진 OCR은 별개다. 열람 코드 N은 만료 또는 허락 자료를 함께 뜻하므로 그 값만으로 재배포 조건을 확정하지 않는다. 공개 전문 API·정확한 재사용 텍스트는 미확보이며 자동 OCR을 원문으로 제공하지 않는다. 공유마당 구운몽 [11213979](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200019&wrtSn=11213979)·[11213978](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200019&wrtSn=11213978)도 만료 표시를 확인했지만 PDF만 확인했다.

## 기준 작품별 결정

| 작품 | 확보물 | 제품 공급 결정 / 미해결 |
| --- | --- | --- |
| 사미인곡 | 공유마당 TXT + 만료 표시 | R-04에서 현대역 분리 후 제공. 저본 미상 표시 |
| 청산별곡 | AKS 원고의 8연 전사 + 원고 이용 안내 | R-05에서 명시적 이용허락·출처 표시 계약으로 제공 |
| 관동별곡 | 정철 TXT + 만료 표시 | R-05 제공. 안축의 동명이작은 텍스트 미확보로 별도 유지 |
| 규원가 | TXT + 만료 표시 | R-05 제공. 귀속 이견·각주 표지·저본 미상 유지 |
| 홍길동전 | 경판30장·완판36장 TXT + 만료 표시 | R-05 별도 판본 제공. 판본 선택 필수·귀속 이견 유지 |
| 구운몽 | NL 브라우저 PDF, 공유마당 PDF | 텍스트 미공급. 서지 링크 탐색만 가능하며, 대조는 교사가 별도로 확보해 제출한 본문(BYO)에 한함 |

공개 API 키 대기 때문에 이 전체 작업이 막힌 것은 아니다. 실제 제품 공급 완료 여부는 후속 PR의 manifest·해시·조회·검증 테스트로 판단한다. 교과서와의 글자 대조·교사 감수·구운몽 전사 확보는 남아 있다.

## 수집 증거와 구간 검사
