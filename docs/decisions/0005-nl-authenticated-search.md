# NL 인증 API 실증과 고전 원문 접근 범위

## 결정과 조사 방법

2026-11-03 발급 키로 [소장자료 API](https://www.nl.go.kr/NL/contents/N31101030700.do)를 직접 호출했다. 이슈 [#29](https://github.com/kingjiwoo/korean-lit-mcp/issues/29)의 PR-B다. 키·인증 URL·응답의 paramData·원문 전문은 저장하거나 공개하지 않았다. 공개 서지 항목만 선별 기록하며, UTF-8 XML 응답과 실제 MCP 호출을 별도로 확인했다.

결론은 **인증된 서지 검색과 원문 뷰어 링크 발견은 가능하지만, 재배포할 수 있는 텍스트 전문 API는 확인하지 못했다**이다. `available_text=false`, `copyright=unknown`을 유지한다. `get_passage`에 NL ID를 연결하지 않는다.

## 실제 검색 결과

## 뷰어 접근과 한계

API가 준 구형 뷰어 진입 경로를 홍길동전·구운몽·송강가사·악장가사 제어번호로 별도 HTTP 조회했다. HTTP 200 HTML은 텍스트 전문이 아니라 `/main.wviewer`로 이동시키는 JavaScript 래퍼였다. 같은 호스트에서 그 이동 경로를 조회한 응답은 404였다. 실제 브라우저 렌더링·기관망·세션별 열람, 이미지/PDF 다운로드·OCR 텍스트는 확인하지 못했다. 따라서 관외 무료 표시는 **기관 메타데이터의 접근 안내**이며 이번 조사에서 페이지 열람 성공까지 입증한 것은 아니다.

소장자료 XML에는 원문 텍스트·행 주소·검수 해시가 없었다. 뷰어 존재로 이미지/PDF 공급 방식을 확정하거나 미공개 내부 API를 공개 전문 API로 연결하지 않는다. 무료 열람은 전사문·번역·현대 편집물의 복제·재배포 허락도 아니다. 전문 공급 후속 #30은 판본별 실제 데이터·재사용 조건과 글자 단위 대조가 필요하다.

## 클라이언트 수정과 계약

- 실제 XML에는 `control_no`가 비어 있고 `id`만 있는 자료가 있다. 둘 다 없거나 형식이 잘못된 경우만 오류로 처리한다.
- `record_id`는 종키 `id`를 우선 사용한다. 제어번호는 동일 책의 온라인·오프라인 레코드나 여러 기사에서 재사용될 수 있으므로 레코드를 합치지 않는다. 호환 `work_id`는 제어번호가 있으면 기존 값을 유지하고, 없으면 `nl-id-...`로 반환한다. 둘 다 검수 원문 ID는 아니다.
- 자료유형·발행사항·원래 연도 문자열·상세/원문 링크·기관 열람 코드/설명을 반환한다. `이용불가`와 안전하지 않은 링크는 null이다. 인증키가 레코드에 반사되면 캐시·결과에 남기지 않고 명시적 오류로 거부한다.
- 연도는 명시적인 서기 연도·날짜 또는 괄호 안 서기만 읽는다. `檀紀4283(1950)`을 4283년으로 처리하지 않고, 불분명한 `단기429219`는 null로 남긴다. 연도 뒤에 개정 등의 부가문구가 있고 명시적인 서기를 확정하지 못한 경우도 null이며 연도 필터에서 제외된다고 응답에 알린다.
- `nl_category=old_books`를 선택하면 검증한 `category=고문헌` 조건으로 NL 검색을 좁힌다. 기본 all과 캐시를 분리한다. 이 조건은 내장 검수 작품 목록을 분류하지 않는다.
- `offerDcode2s=CH44/CH4G` 단독 조건은 대조 호출에서 동일 결과를 돌려 필터 적용을 입증하지 못했다. 온라인자료 조건을 함께 써도 CH44가 아닌 자료가 섞였다. 검증된 고문헌 category만 제품에 연결하고, 해당 DB 전용 필터나 KORCIS 전문 연동은 추가하지 않는다.

## 오류·쿼터·테스트

인증 성공 XML과 HTTP 200을 확인했다. 키 없음/무효 010·011, 0건, 원문 미제공, 제한 열람을 구분한다. 문서의 012는 **500건 이후 결과 탐색 제한**이며 일일 호출량이나 월 쿼터가 아니다. 일일 허용량과 한도 도달 시 동작은 실제로 소진 시험하지 않았고 미확인이다. 429·타임아웃·크기 상한과 기존 메모리 캐시를 유지한다.

CI는 키 없는 합성 XML로 빈 제어번호·다른 자료 ID·중복 제어번호·연도·링크·비밀 반사 거부·category 캐시를 검사한다. 실제 기관 호출과 Vercel 검증은 별도 결과로 기록한다. 실증 자료를 테스트 fixture로 복사하지 않는다.
