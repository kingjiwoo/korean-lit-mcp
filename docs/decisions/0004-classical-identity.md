# 고전 작품 후보와 검색 레코드 구분

## 범위

이슈 [#28](https://github.com/kingjiwoo/korean-lit-mcp/issues/28)의 키 없는 작업이다.
규원가·사미인곡·홍길동전 세 작품의 발견용 메타데이터를 코드에 검수 등록한다.
전문이나 판본을 추가하지 않으며 NL 키도 사용하지 않는다.

## 근거와 변경 이력

2026-11-01 공식 기관 자료를 대조하고 제목·이칭·귀속 정보를 요약 등록했다.
본문·번역·주석은 복제하지 않았다. 이후 변경은 코드와 Git 이력으로 검토한다.
UTF-8 문자열은 검색 비교에서만 NFC·공백·가운뎃점 정규화를 적용한다.

## 응답 계약

`work_candidates`는 요청 검색어가 검수 이칭과 정확히 대응할 때만 반환한다.
`identity_id`는 발견용 ID이며 `get_passage` 작품 ID가 아니다.
`attested_in`은 참고 문헌 정보이고 ITKC 레코드·판본과의 연결이 아니다.
미등록 검색어의 후보 0건은 작품 부재를 뜻하지 않는다.
기관 검색어를 자동 번역·치환하거나 이칭마다 추가 호출하지 않는다.

레코드의 `match_kind`는 문자열 비교 결과다.

- `title_candidate`: 기사명이 검수 이칭과 일치. 동명이작·본문·판본 확인 필요.
- `body_mention`: 제목은 불일치하지만 발췌에 이칭 문자열이 있음. 작품 동일성은 미확인.
- `unconfirmed_search_match`: 등록 검색어인데 제목·발췌의 알려진 이칭과 불일치. 규원가→九原可 같은 사례를 분리.
- `unclassified`: 검수 이칭 미등록이라 분류하지 않음.

`identity_status=unconfirmed`, `work_author=null`, `available_text=false`를 유지한다.
작품 후보의 귀속 정보로 `document_author`를 덮어쓰지 않는다.
강조 태그는 비교용 복사본에서만 제거하고 원래 발췌는 보존한다.
동음어를 자동 제외하지도, 제목만으로 원문·작가를 확정하지도 않는다.

## 검증과 남은 조건

합성 XML과 MCP 직렬화로 동음 일치·한자/옛표기 이칭·본문 언급·동명 기사를 검증한다.
작품·레코드 연결의 확정, 모든 고전 목록, 원문 확보와 NL 실증은 별도다.
