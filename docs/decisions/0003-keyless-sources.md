# 키 없는 고전 자료 출처 실증

확인일: 2026-11-01. 웹 목록, 공식 API, 텍스트 전문을 구분한다. 이 문서는 새 출처의 배포 완료 기록이 아니다.

## 한국학자료센터

공식 [자료공개센터](https://kostma.aks.ac.kr/OpenAPI/OpenAPI.aspx)와 [문헌정보 규격](https://kostma.aks.ac.kr/OpenAPI/HowTo/howTo.aspx?SideMenu=DataAPI&Body=DES)을 확인했다. 현재 화면의 규격 표와 TEST URL에는 key·section이 없고, 실제 HTTPS 요청도 키 없이 XML을 반환했다. HTML 소스에는 key·section을 필수로 적었던 과거 행이 주석 처리돼 남아 있으나 이를 현행 요구사항으로 해석하지 않는다. 확인된 무키 문헌정보 검색 범위로 기록하며 쿼터·대량 활용·전문 제공은 별도 확인한다.

`request.aspx`에 query, ipp=1을 전달한 결과다. 총건수는 문헌 목록 수이며 작품 전문이나 전사 텍스트 수가 아니다. 확인일의 관측값으로 재조회 시 달라질 수 있다.

| 검색어 | 목록 총건수 | 첫 자료명 |
| --- | ---: | --- |
| 사미인곡 | 0 | 없음 |
| 청산별곡 | 0 | 없음 |
| 관동별곡 | 0 | 없음 |
| 홍길동전 | 0 | 없음 |
| 洪吉童傳 | 3 | 홍길동젼(洪吉童傳) |
| 구운몽 | 11 | 구운몽(九雲夢) |
| 송강가사 | 4 | 송강가사(松江歌辭) |
| 악장가사 | 0 | 없음 |

홍길동전은 현대 한글 제목만으로 검색하면 누락됐다. 이후 작품별 검토된 이칭(홍길동젼·洪吉童傳 등)을 연결해야 한다. 전체 검색어를 임의 한자로 번역하거나 제목만 보고 판본을 합치지 않는다. 시가는 개별 작품명이 아니라 수록 문헌을 찾아야 할 수 있으나 송강가사 4건이 곧 사미인곡·관동별곡 원문 4건이라는 뜻은 아니다.

목록 API가 반환한 UCI와 자료 링크는 문헌 탐색에 쓸 수 있다. 구운몽 첫 레코드의 UCI `RIKS+CRMA+KSM-WZ.1803.0000-20140421.TOYO_1459`로 [원문텍스트 규격](https://kostma.aks.ac.kr/OpenAPI/HowTo/howTo.aspx?SideMenu=DataAPI&Body=TXT)의 `req_text.aspx`를 조회했지만 XML ksm 응답 대신 HTML이 반환됐고 전문을 확인하지 못했다. 같은 UCI를 인코딩해 재조회한 응답은 HTTP 404, Content-Type text/html이었다. curl -f가 오류 본문을 수집하지 않아 0바이트로 보고했으며 전문 XML 크기라고 해석하지 않는다. 홈페이지에서 원문텍스트·이미지 API 메뉴 일부는 HTML 주석으로 숨겨져 있다. 과거 규격 페이지가 남아 있다는 사실만으로 운영 중인 전문 API라고 판단하지 않는다.

실증 환경은 Python 3.13.6, httpx 0.28.1, OpenSSL 3.0.16이다. curl의 기본 인증서 검증을 유지한 요청은 성공했지만 실제 협상은 TLS 1.2 / RC4-SHA였다. 프로젝트 Python/httpx 요청은 `SSL: WRONG_SIGNATURE_TYPE`로 연결에 실패했고 TLS 1.3 전용 연결도 실패했다. curl 성공을 현재 서버에서 안전하게 동작하는 HTTPS 연결의 증거로 삼지 않는다. TLS 검증 해제, 보안 수준 하향, HTTP 전환으로 해결하지 않았다. 따라서 현재 Python 서버용 커넥터를 완료된 기능으로 추가하지 않는다. 기관 HTTPS 호환성·현행 인증·쿼터·목록/전문 이용 조건을 확인한 뒤 실제 서버 환경에서 재실증한다. 검색 API 주소를 구현할 때는 사용자 결정대로 환경변수에 둔다.

## 국립중앙도서관

사용자가 제공한 소장자료 OpenAPI URL에서 key를 비우고 사미인곡·청산별곡·관동별곡·홍길동전·구운몽을 각각 조회했다. 모두 HTTP 200이지만 error_code 010(키 없음)이었다. 검색 성공이나 자료 미수록으로 처리하지 않는다. 키 신청은 이미 진행 중이다.

[홍길동전 디지털 컬렉션](https://www.nl.go.kr/NL/contents/N20103000000.do?schIdSub=CO0000004032&schM=contView)에서는 1934년 세창서관 판본과 원문보기 안내를 확인했다. 이는 웹 자료 존재 근거이며 인증된 API 성공이나 텍스트 다운로드 근거가 아니다. 다른 웹 검색 결과에서는 같은 제목의 음악 자료와 현대 편집본도 나왔다. 본문/이미지 구분과 열람 장소·과금·재사용 조건을 판본별로 확인해야 한다.

## 채택 순서와 종료 조건

1. 현재 동작하는 ITKC 발췌 검색은 유지하고 문헌 저자·검색 범위를 명시한다.
2. 한국학자료센터는 무키 문헌 목록 후보로 확보한다. HTTPS 호환성과 현행 제공 계약이 해결되면 검색 커넥터 PR로 진행한다.
3. 국립중앙도서관은 발급 키로 서지·원문 링크·자료 유형을 실증한다.
4. 원문 텍스트 경로와 판본별 재사용 근거가 확인된 데이터만 get_passage/verify_quote에 연결한다. 이미지/OCR 추정 텍스트를 검수 전문으로 표시하지 않는다.

공식 페이지와 실제 호출 결과의 차이, 연결 실패, 0건은 각각 기록했다. 원문·전체 API 응답을 fixture로 저장하지 않았고 구현 검사는 합성 자료만 쓴다.
