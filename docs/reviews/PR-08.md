# PR 08 검증 기록

- 기준: PR 07. 범위는 컨테이너 CI, 교사·운영 안내, 진행 상태와 최종 회귀 보완.
- 교차 리뷰: Claude Code `claude-opus-4-7`, CI·문서 전체와 최종 코드 보완을 읽기 전용 스냅샷으로 검토했다.
- 결과: CI·컨테이너·외부 실증 대기 표시는 적절하며 필수 구현 결함이 없었다. `ponytail`은 사용자가 지정한 실제 리뷰 스킬 이름이므로 오타라는 지적은 반영하지 않았다.
- 최종 보완: 임의 기관 오류 내용을 반사하지 않도록 숫자 오류 코드만 허용, 원문·해시 실패 시 초안 검사 범위 유지, 토큰 회수와 Host URL 처리 회귀 테스트. 수정 후 Opus 재리뷰에서 결함이 없었다.
- 기관 실패가 로컬 결과에 가려져도 운영자가 알 수 있게 내용 없는 업스트림 결과·오류 코드 지표를 추가했다. 해당 경로도 Opus에 재검토했고, 고정 코드만 로그에 포함되며 비밀값이 없는지 회귀 테스트로 확인했다.
- GitHub 컨테이너 CI의 첫 준비 확인이 연결 재설정(exit 56)으로 실패했다. 첫 TCP 연결을 재설정하고 두 번째에 200을 반환하는 재현에서 기존 명령은 1회 후 실패, `--retry-all-errors` 적용 명령은 2회 후 성공했다. 읽기 전용 health GET의 기존 30초 제한을 유지하며 준비 오류를 재시도하도록 수정했다. 서버 코드 변경 없이 CI 준비 확인만 수정했고 Claude Opus 재리뷰에서 승인했다. Ponytail 검토에서도 별도 스크립트·의존성 없이 원인에 맞는 최소 수정임을 확인했다.
