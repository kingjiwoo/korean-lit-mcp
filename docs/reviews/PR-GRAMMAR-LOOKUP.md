# G-02 문법 조회 로직 리뷰

범위: `grammar.py`의 입력·자료 모델, 크기 제한 로더, 시대별 용어·별칭 조회와 관련 테스트. G-01 자료 PR #37을 통합한 develop에서 검증하며 MCP 등록은 G-03에 둔다.

Claude 사용량 한도가 계속 유효해 사용자 승인 예외로 별도 Codex CLI `gpt-6.1-sol` 읽기 전용 세션에 전체 구현·테스트·계약·공통 자료 로더·검수 데이터를 제공했다. 도구·hooks·plugins·MCP·추가 위임을 끈 대체 독립 리뷰이며 제품 간 교차 리뷰가 아니다.

리뷰가 지적한 `casefold()`는 NFC·공백만 허용하는 검색 계약보다 넓은 동치를 만들었다. 이를 제거하고 ß/ss가 구별되는 회귀 검증을 추가했다. 수정한 전체 코드·테스트를 같은 조건의 새 Codex 세션에서 재검토해 승인을 받았다. 나머지 시대 격리·출처/권리·자료 오류·용량·경로·응답 복사·미검색 범위에는 확정 지적이 없었다.

Ponytail 리뷰: 기존 Input·Envelope·read_limited·SourceError를 재사용하고, 기존 문학 search_key가 아래아를 제거하므로 문법에 필요한 NFC·공백 키만 별도로 둔다. 네트워크·DB·LLM·새 의존성·요청 저장은 없다. CC 자료를 퍼블릭 도메인으로 표시하지 않으며 응답에 이용조건을 유지한다.

최종 필수 검사 결과는 PR 본문에 기록한다. 실제 MCP 등록·원격 HTTP·production은 다음 단계이며 이 PR의 로컬 검사 성공으로 완료 처리하지 않는다.
