# PR 09 검증 기록

## 목표와 범위

사용자가 결정한 운영 방식은 한 사람이 배포하면 누구나 URL만 등록해 사용하는 공개 MCP다. `chore/pilot-deployment`의 `260377d`를 기준으로 `feature/public-access`에서 작업했다. 기존 사용자 변경은 없었다.

공유 토큰 검증을 CLI·HTTP Guard·FastMCP에서 제거하고 모든 호출부·환경변수 예제·컨테이너 CI·테스트·현재 안내를 갱신했다. 입력 크기·읽기 시간·공유 호출 횟수·동시 처리 제한, Host·Origin 검사, 비저장 정책과 내용 없는 로그는 유지한다. 기관 키는 선택적인 서버 비밀값이다. 계정·OAuth·키 발급 페이지·DB·호스팅 설정은 추가하지 않았다.

## 교차 리뷰

Claude Code를 `--model opus`와 도구 없는 읽기 전용 스냅샷으로 실행했다. 응답 모델은 `claude-opus-4-7`이며 구현·호출부·테스트·CI·현재 운영 및 사용자 안내 전체를 검토했다. 결과는 해당 범위 승인, 증명된 결함 없음이다.

공유 한도를 한 사용자가 소진할 수 있고 여러 인스턴스의 상태가 공유되지 않는 한계는 운영 문서에 명시했다. 429·503의 기존 응답 헤더와 고정 재시도 대기 시간은 이번 공개 전환의 새 결함으로 판단하지 않았다. `ponytail`은 실제 리뷰 스킬 이름이므로 오타라는 지적은 반영하지 않았다.

## Ponytail review

What this change does: Makes the three MCP tools public. Users connect with a URL and do not need an account or token.

Looks good. Ship this scoped change.

Checked: every factory caller, CLI startup, HTTP guards, real HTTP clients, CI, configuration, teacher and operator docs. The expected load is a small public pilot sharing one process. Removing auth also removes its old tests and configuration; no replacement auth layer, dependency or storage is needed.

Not checked: live Claude account, authenticated institutional search, hosted deployment, platform-wide traffic and cost controls.

## 검증

공개 `tools/list` 테스트가 변경 전에는 401로 실패하고 변경 후에는 200으로 성공하는 것을 재현했다.

`MCP_AUTH_TOKEN`·`NL_API_KEY`를 설정하지 않고 CLI를 기동해 실제 HTTP 테스트를 포함한 75개 테스트를 모두 통과했다. 이전 MCP `2025-11-25` 초기화와 현재 SDK의 도구 목록·원문 조회·인용 검증을 포함한다. 필요 없어진 비공개 인증 테스트를 제거해 이전 78개에서 75개가 됐다.

Ruff lint·format, mypy, Markdown lint, `git diff --check`도 통과했다. 기본 `pytest`는 실제 HTTP 주소를 생략하면 74개 통과·1개 건너뛰기이며, 위 75개 결과는 임시 서버 주소를 설정해 전체 실행한 결과다. 실제 Claude 연결·기관 API 성공 응답·원격 배포는 별도로 검증해야 한다.
