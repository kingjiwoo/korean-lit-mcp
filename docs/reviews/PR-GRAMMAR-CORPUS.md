# G-01 문법 자료·PR 계획 리뷰

범위: 현대 8·중세 2·근대 표기 1항목, 출처·이용조건·예시·시대·별칭 검토와 G-01~G-04 실행 계획. API 키·LLM 호출·새 런타임 도구는 추가하지 않는다.

Claude Code `opus` 실행은 사용량 한도 오류로 실패했다. 오류는 복구 시각을 23:40 Asia/Seoul로 안내했으며 실제 응답 모델·리뷰 결과는 없었다. 사용자가 한도 동안 대체를 허용해 별도 Codex CLI 세션에 `gpt-6.1-sol`을 지정했다. CLI의 모델·read-only sandbox·approval never 배너와 정상 종료를 확인했다. 도구·추가 위임·hooks·plugins·MCP 연결을 끈 제공 스냅샷 검토이며 제품 간 교차 리뷰로 표시하지 않는다.

독립 리뷰가 지적한 개별 항목의 본문·권리 증거 누락을 실제 공식 HTML의 해당 구간으로 보완했다. 기본 TLS 검증을 유지한 curl로 뜻풀이·별칭·출처·CC BY-SA 표시·자료 버전을 대조했다. ㅎ 받침 체언에서 거센소리를 결합 상대처럼 읽을 수 있던 설명을 예사소리 ㄱ/ㄷ/ㅂ과 결합해 ㅋ/ㅌ/ㅍ이 됨으로 수정했다. 직접 근거가 부족한 별칭을 제거했다. 재검토는 남은 별칭 정리 후 자료·계획 승인 가능이라고 답했고 해당 별칭도 제거했다.

Ponytail 리뷰: 기존 파일형 자료 구조와 일반 코드 조회를 사용하며 새 DB·LLM·형태소 분석·자동 수집을 도입하지 않는다. 텍스트 라이선스와 미디어 권리를 분리하고 사전 형태 예시를 실제 문헌 인용으로 표시하지 않는다. 초기 수록 범위를 전체 문법 지원으로 표시하지 않는다.

검증: 11개 항목의 시대별 수·고유 ID·필수 메타데이터·출처/예시 연결을 assert로 확인했다. 최종 Python·Markdown 검사는 PR 본문에 기록한다. 기관·교사 감수, 런타임 문법 조회와 원격 배포는 후속 단계다.
