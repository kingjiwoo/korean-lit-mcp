# G-03 문법 MCP·배포 연결 리뷰

기준은 G-01 PR #37·G-02 PR #38을 병합한 develop이다. 범위는 `lookup_grammar` 등록, 명시적 자료 주입·기동 로딩, 내용 없는 지표, Vercel `data/**` 번들, 교사·운영 안내와 HTTP 검증이다.

사용자 승인에 따라 Claude 한도 동안 별도 Codex CLI `gpt-6.1-sol` 읽기 전용 대체 독립 리뷰를 수행했다. 전체 diff와 서버·런타임·지표·조회 코드·계약·관련 테스트·배포 설정·안내 문서를 제공했고 도구·수정·추가 위임을 끈 정적 검토에서 승인받았다. 제품 간 교차 리뷰가 아니다. 실제 원자료 전체·기관 권리 검증·CI·production은 이 정적 리뷰가 새로 인증한 범위가 아니며 앞선 자료 검토와 후속 실증으로 구분한다.

Ponytail 리뷰: 기존 팩토리의 명시적 주입과 read-only 자료를 사용한다. 새 DB·키·LLM·추론·요청 보관·새 의존성이 없다. 기존 Host·Origin·본문·호출 제한을 변경하지 않았고 질의·응답 내용은 지표에 넣지 않는다. 데이터가 누락·손상되면 실제 실행 경로의 기동이 실패한다.

키 없는 로컬 CLI 서버를 기동해 실제 HTTP 검사를 포함한 149개 테스트가 통과했다. 세 시대·별칭·미검색·상한 거부·PUA 문자열 전달과 기존 원문 조회·판본/해시 인용 검증을 확인했다. 네트워크를 차단한 in-memory MCP 테스트도 통과했다. SDK v2 주석 필드는 `read_only_hint`로 확인해 deprecation warning을 숨기지 않는다. 최종 정적·문서 검사와 CI는 PR 본문, main 자동 배포·공개 검증은 G-04 릴리스 PR에 기록한다.
